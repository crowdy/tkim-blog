## Resolved open questions

### Q1: 2.5.3 비홀로노믹 구속 처리

§1.1.2 는 *홀로노믹* 구속만 다룬다고 박았다. 2.5.3 에서 비홀로노믹이 등장하므로 다음과 같이 정리:

- **2.5.3 의 본문 핵심**: (a) 비홀로노믹 구속의 정의 — 속도 의존 구속 $\sum a^\alpha_i \dot q^i + a^\alpha_0 = 0$ 으로 *적분 불가능* (Frobenius 조건 위반). (b) 왜 라그랑주식이 *그대로* 통하지 않는가 — 가상 변위 직교 조건이 *시간 고정* 만으로는 깨진다. (c) 다랑베르 일반화 + 라그랑주 곱셈자 형식: 운동방정식이 *곱셈자 $\lambda^\alpha$* 와 함께 적힘.
- **예시**: 미끄러지지 않고 구르는 동전, 스케이트 날 (skater).
- §1.1.2 의 *홀로노믹* 강조와의 일관성: §1.1.2 가 *§1 의 범위 한정* 으로 홀로노믹만 다룬 것을 본 절에서 명시.

### Q2: *擾座標* (quasi-coordinate) 의 한국어 — **준좌표**

원서의 "擾座標" 는 일본어 학술어. 한국어 직역은 어색 ("뒤섞인 좌표"?). 표준 영어 학술 용어 *quasi-coordinate* 의 의미가 "*적분 불가능한 좌표*" 이므로, 한국어로 **준좌표 (quasi-coordinate)** 로 통일. 첫 등장 (2.4.1) 에서 *quasi-coordinate* 영문 + *적분 불가능 좌표* 설명 병기.

### Q3: 코드 비중

章 1 의 81% 코드 / 19% 도해 비율을 §2 에서도 비슷하게 유지. 추상 절 약 3 편만 코드 없이:

- **2.3.2 좌표계 무관 표현** — 좌표 자유 형식의 추상화. 도해.
- **2.5.3 비홀로노믹 구속** — 코드로 보여주기 까다로움. 도해.
