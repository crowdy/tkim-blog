# 분자의 모양과 전자 상태 — VSEPR, 혼성화, 텀 기호

> 원자가전자의 수만으로 분자 모양을 예측하고, 같은 논리로 원자 바닥상태에 $^{2S+1}L_J$ 라는 이름표를 붙인다.

## 들어가며

7장에서는 다전자 분자의 슬레이터 행렬식과 분자궤도(MO)를 다뤘다. 이번 장은 좀 더 손으로 잡히는 그림 — *분자가 왜 그 모양을 띠는가* — 로 내려온다. H$_2$O 가 굽고, NH$_3$ 가 우산이고, CH$_4$ 가 정사면체인 이유는, 풀어 보면 모두 "전자쌍은 가능한 한 멀리 떨어지려 한다"는 한 문장의 결과다. 이 장을 끝내면 독자는 중심 원자 주위의 원자가 수와 외톨이쌍 수만으로 분자 모양을 즉시 예측할 수 있고, 그 예측이 어떻게 혼성궤도라는 *수학적* 그림과 맞물리는지, 또 원자 수준에서는 같은 사고가 $^{2S+1}L_J$ 라는 텀 기호로 정리된다는 점까지 한 줄로 설명할 수 있다.

## 본론 1 — VSEPR: 전자쌍이 자리를 정한다

**VSEPR(valence-shell electron-pair repulsion)** 모델의 전제는 단 하나다. 중심 원자 주위의 전자쌍 — 결합쌍이든 외톨이쌍(lone pair)이든 — 은 서로 반발하므로, 가능한 한 멀리 떨어지는 배치를 택한다. 이 한 줄에서 모양이 결정된다.

세는 양은 **입체수(steric number, SN)** 다.

$$
\text{SN} = (\text{결합한 원자 수}) + (\text{외톨이쌍 수})
$$

입체수별로 떨어지는 표준 배치는 다음과 같다.

- **SN = 2** → 직선형, 결합각 180°. 예: BeCl$_2$, CO$_2$.
- **SN = 3** → 평면 삼각형, 120°. 예: BF$_3$.
- **SN = 4** → 정사면체, 109.5°. 예: CH$_4$. 외톨이쌍 1개면 **삼각뿔(trigonal pyramidal)** 로 무너져 NH$_3$ (약 107°). 외톨이쌍 2개면 **굽은꼴(bent)** 로 더 좁혀져 H$_2$O (약 104.5°).
- **SN = 5** → 삼각쌍뿔(trigonal bipyramidal), 축 90°·적도 120°. 예: PCl$_5$.
- **SN = 6** → 정팔면체, 90°. 예: SF$_6$.

H$_2$O 의 결합각이 정사면체 이상값 109.5° 보다 *더 좁은* 104.5° 인 데는 한 가지 이유가 있다. 외톨이쌍은 양성자에 묶여 있지 않아 공간적으로 더 퍼져 있고, 결합쌍보다 더 많은 자리를 차지한다. 그래서 외톨이쌍이 결합쌍을 *바깥쪽에서 안쪽으로* 밀어 각도를 줄인다. NH$_3$ 의 107° 도 같은 효과의 약한 버전이다. VSEPR 은 양자역학을 동원하지 않고도 이 정도까지 정량적으로 맞춘다.

## 본론 2 — 혼성화: 원자궤도를 다시 빚는 법

VSEPR 이 *어떤 모양이 되는가* 를 말한다면, **혼성화(hybridization)** 는 *그 모양에 맞춰 중심 원자의 원자궤도(AO)를 어떻게 재조합해야 하는가* 를 말한다.

탄소의 바닥상태 전자배치는 $1s^2 2s^2 2p^2$ 이지만, CH$_4$ 처럼 동등한 네 결합을 만들 때 우리는 $2s$ 1개와 $2p$ 3개를 섞어 네 개의 등가 혼성궤도 $sp^3$ 를 만든다. 이 네 궤도는 정사면체의 네 꼭짓점을 향한다. BF$_3$ 나 에틸렌의 탄소처럼 평면 삼각형이 필요하면 $2s$ + $2p_x$ + $2p_y$ 를 섞어 세 개의 $sp^2$ 와 하나의 남는 $2p_z$ 가 되고, 아세틸렌의 탄소처럼 직선이 필요하면 $2s$ + $2p_x$ 만 섞어 두 개의 $sp$ 와 두 개의 남는 $2p$ 가 된다. 규칙은 한 줄이다.

$$
\text{입체수} = \text{혼성궤도 수}
$$

남은 비혼성 $p$ 궤도는 옆 원자의 같은 $p$ 와 만나 $\pi$ 결합을 만든다(6장). 이중결합은 $sp^2$ + $\pi$, 삼중결합은 $sp$ + $\pi \times 2$ 다.

한 가지 주의. 혼성화는 *측정된 사실* 이 아니라 *사후 기술* 이다. 분자가 정사면체 모양을 한다는 실험 결과를 받아들고, 그것에 맞는 궤도 기저를 *우리가 선택* 한 것이다. 그래도 이 기술 덕분에 결합각, $\pi$ 의 존재, 평면성 같은 성질을 한꺼번에 정리할 수 있다.

## 본론 3 — 원자의 텀 기호 $^{2S+1}L_J$

같은 사고를 *원자* 수준에서 정리하면 **텀 기호(term symbol)** $^{2S+1}L_J$ 가 된다. 한 원자의 전체 궤도 각운동량을 $L$, 전체 스핀을 $S$ (대문자, 모든 전자의 합), 전체 각운동량을 $J = L + S$ 라 부르자. 표기법은 다음과 같다.

- 위 첨자 $2S+1$ — **다중도(multiplicity)**.
- 가운데 글자 — $L$ 값. $L = 0, 1, 2, 3 \to$ S, P, D, F.
- 아래 첨자 — $J$.

이 이름표는 같은 전자배치 안에서 미세하게 다른 상태들을 구분하는 데 쓰인다. 어느 것이 *바닥상태* 가 되는지는 **훈트의 법칙(Hund's rules)** 이 결정한다.

1. $S$ 를 가능한 한 크게.
2. 같은 $S$ 안에서는 $L$ 을 가능한 한 크게.
3. 반쪽보다 덜 찬 껍질에서는 $J$ 를 가능한 한 작게 (반쪽 이상이면 반대).

질소 ($1s^2 2s^2 2p^3$) 로 직접 해 보자. $2p$ 의 세 자리 $m_\ell = -1, 0, +1$ 에 전자 셋이 들어가는데, 훈트 1번이 셋을 모두 같은 스핀으로 정렬시켜 $S = 3/2$. 자기양자수 합은 $-1 + 0 + 1 = 0$, 즉 $L = 0$ → 글자는 S. $J = |L - S|$ 부터 $|L + S|$ 까지 중에서 반쪽보다 덜 찬 경우라면 가장 작은 값을 고른다: $J = 3/2$. 결과는

$$
^4 S_{3/2}
$$

이것이 질소의 바닥상태 이름표다. 다중도 4는 "같은 에너지의 마이크로상태가 $2S+1 = 4$ 가지"라는 뜻이다.

분자에서도 같은 종류의 기호가 있다. H$_2$ 의 바닥상태는 $^1\Sigma_g^+$, O$_2$ 의 바닥상태는 $^3\Sigma_g^-$ (그래서 산소 분자는 상자성이다). $\Sigma, \Pi, \Delta$ 는 분자축 방향 각운동량의 $L$ 대응이고, $g/u$ 는 반전 대칭, $\pm$ 는 거울 대칭의 라벨이다. 더 깊은 분류는 9장 분광학에서 다시 만난다.

## 파이썬으로 확인

```python
# VSEPR 분류기: 결합 수와 외톨이쌍 수만으로 입체수와 모양을 돌려준다.
# 실험적 결합각도 함께 출력해 본다.

SHAPES = {
    (2, 0): ("linear",               180.0),
    (3, 0): ("trigonal planar",      120.0),
    (4, 0): ("tetrahedral",          109.5),
    (3, 1): ("trigonal pyramidal",   107.0),
    (2, 2): ("bent",                 104.5),
    (5, 0): ("trigonal bipyramidal",  90.0),
    (6, 0): ("octahedral",            90.0),
}

def vsepr(bonding, lone):
    sn = bonding + lone
    shape, angle = SHAPES[(bonding, lone)]
    return sn, shape, angle

cases = [
    ("H2O",   2, 2),
    ("NH3",   3, 1),
    ("CH4",   4, 0),
    ("BeCl2", 2, 0),
    ("BF3",   3, 0),
    ("PCl5",  5, 0),
    ("SF6",   6, 0),
]

print(f"{'formula':<6}  {'SN':>2}  {'shape':<22}  angle")
print("-" * 46)
for formula, b, l in cases:
    sn, shape, angle = vsepr(b, l)
    print(f"{formula:<6}  {sn:>2}  {shape:<22}  {angle:5.1f}°")
```

출력의 각 줄이 본문에서 예측한 모양·각도와 일치한다면, "전자쌍은 멀리 떨어지려 한다"는 한 줄짜리 규칙으로 일곱 분자의 형상을 손에 쥔 셈이다.
