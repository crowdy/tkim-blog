# 構造と性質 — 導電性高分子・OLED・そして14章の終わり

> 共役鎖の長さが色を決め、同じ論理が導電性高分子と OLED へつながる — 原子から物質まで、14 章の旅を閉じる章。

## はじめに

最後の章だ。12 章で固体のバンド構造を見たなら、本章はその論理を *分子が作った物質* — 導電性高分子、有機半導体、OLED — へ持っていく。中心となる道具はすでに 7 章で出会った: 共役 π 系を 1 次元の箱で近似すると、鎖が長いほど HOMO–LUMO ギャップが縮むという絵だ。本章を終えると読者は、共役長がどのように分子の色を決めるかを定量的に計算でき、ポリアセチレンがなぜドーピングで金属になるのか、OLED ピクセルの色がどこから来るのかを一行で言える。

## 本論 1 — 共役長が色を決める

炭素 $N$ 個が一列に共役したポリエンを考えよう。π 電子雲を長さ $L = (N-1)d$ の 1 次元の箱に閉じ込められたものと近似すると(C–C 間隔 $d \approx 1.4$ Å)、2 章の箱の中の粒子の公式がそのまま適用される。

$$
E_n = \frac{n^2 \pi^2 \hbar^2}{2 m_e L^2}
$$

ここで $\hbar$(h-bar、換算プランク定数)、$m_e$ は電子質量。パウリ原理で $N/2$ 個の準位が満たされるので HOMO は $n = N/2$、LUMO は $n = N/2 + 1$ であり、ギャップは

$$
\Delta E = E_{N/2+1} - E_{N/2} = \frac{\pi^2 \hbar^2}{2 m_e L^2}\,(N+1).
$$

$L = (N-1)d$ を入れると $\Delta E \propto (N+1)/(N-1)^2 \sim 1/N$ — 鎖が長いほどギャップが縮み、吸収波長 $\lambda = hc/\Delta E$ はほぼ $N$ に比例して長くなる。ニンジンのベータカロテンのような長い共役鎖は可視光の青/緑を吸収してオレンジ色に見える。分子の色という日常の現象が、鎖の長さというたった一つの整数に帰着する。

## 本論 2 — 導電性高分子

長い共役鎖の極端が **導電性高分子** だ。トランス-ポリアセチレン $(\text{CH})_n$ は、1977 年にヒーガー・マクダイアミッド・白川が示したブレークスルー物質である — 有機高分子がドーピングで金属レベルの伝導性を持ちうるということ。この業績で三人は 2000 年のノーベル化学賞を受けた。

ドープしていないポリアセチレンは **パイエルス歪み(Peierls distortion)** の基底状態を持つ — 結合長が長い・短いを交互に取る *結合交替(bond alternation)*。この交替が約 1.5 eV のバンドギャップを開く。ドーピング(酸化は電子を抜き、還元は電子を加える)はフェルミ準位を再びバンドの中へ押し込んで伝導性を生む。同じギャップ縮小の論理が、ポリチオフェンや PEDOT-PSS といった他の導電性高分子にもそのまま適用される。

## 本論 3 — OLED、化学が素子に出会う場所

**OLED(organic light-emitting diode)** はサンドイッチ構造だ: 電子輸送層 / 発光有機分子 / 正孔輸送層。電極から注入された電子と正孔が発光分子の上で再結合し、そのエネルギーを $h\nu = E_{\text{HOMO-LUMO}}$ の光子として放出する。発光分子のギャップを — 共役長と置換基で — 調整すれば色が決まる。そうやって携帯電話の画面の青・緑・赤のピクセル発光体が作られる。

素子の観点からは二つの数が重要だ: 外部量子効率(注入した電子あたりに出る光子数)と寿命(劣化までもつ時間)。2026 年現在、最良の青色 OLED は約 20% の効率と 1 万時間の寿命を記録するが、どちらもいまだ活発な研究テーマだ — 青色発光体の大きなギャップが分子をより速く壊すからである。

## Pythonで確かめる

```python
# ポリエンの共役長ごとの HOMO-LUMO 吸収波長と色を表にする。
import numpy as np

h    = 6.62607015e-34
c    = 2.99792458e8
hbar = h / (2 * np.pi)
me   = 9.1093837e-31
eV   = 1.602176634e-19
d    = 1.4e-10        # C-C 間隔 [m]

def color_of(lam_nm):
    bands = [(380,"UV"),(450,"紫"),(490,"青"),(570,"緑"),
             (590,"黄"),(620,"橙"),(750,"赤")]
    for edge, name in bands:
        if lam_nm < edge:
            return name
    return "IR"

print(f"{'N':>3} {'L(nm)':>7} {'dE(eV)':>8} {'lam(nm)':>9}  color")
print("-" * 40)
for N in [4, 6, 8, 10, 14, 22]:
    L = (N - 1) * d
    dE = (np.pi**2 * hbar**2) / (2 * me * L**2) * (N + 1)   # J
    lam_nm = h * c / dE * 1e9
    print(f"{N:>3} {L*1e9:>7.2f} {dE/eV:>8.2f} {lam_nm:>9.1f}  {color_of(lam_nm)}")
```

$N$ が大きくなるにつれて吸収波長が UV から紫・青を経て赤へ移っていけば、「鎖が長いほどギャップが小さくなる」という一行を手に取ったことになる。実際のポリエンの吸収はこの傾向に定性的には従うが正確には合わない — 箱モデルは電子間のクーロン反発と σ–π 結合を無視するからだ。

## おわりに

この本は 0 章で一つの逆説から出発した — 古典物理では原子が $10^{-11}$ 秒で崩壊するはずなのに、世界のすべての原子は無事である。その逆説を解くために、我々は波動関数という言葉を学び(1–2 章)、スピンとスレーター行列式で多電子原子を扱い(3–4 章)、その言葉で結合・分子・光・物質を順に説明してきた(5–13 章)。最後の章で我々は、7 章のヒュッケルのはしごがポリエンの色になり、12 章のバンド構造が OLED ピクセルになるのを見た。原子から物質まで、同じシュレディンガー方程式ひとつが最後まで付き添ってきたのだ。

さらに深く進みたい読者に三冊を勧める。**Szabo & Ostlund, *Modern Quantum Chemistry*** — ハートリー–フォックとその先の方法論を本格的に扱う。**Atkins, *Physical Chemistry* / *Molecular Quantum Mechanics*** — 同じ内容をよりゆっくり、より広く。**Ashcroft & Mermin, *Solid State Physics*** — 12 章で味わったバンド構造の本格的な教科書。この 14 章が、それらの本を開いたときに最初のページが見慣れないものでないようにする橋であったなら、それで十分だ。
