# 分子軌道理論 — LCAOと結合/反結合

> 原子軌道を足したり引いたりするだけの単純な処方から、結合と反結合、そしてσとπの絵がどう自動的に落ちてくるか — H₂⁺ 一分子で最後まで追いかける。

## はじめに

5 章では結合を「二つの原子が電子対を共有する」というルイス式の絵で扱った。本章ではその絵を量子力学に置き換える。中心となる道具は **LCAO(Linear Combination of Atomic Orbitals, 原子軌道の線形結合)** — 分子軌道を原子軌道の線形結合として書き下すという、見かけ上あまりに単純な処方である。この一行から、結合性軌道と反結合性軌道、σ と π、そして「なぜ He₂ は安定な分子にならないか」までの定性的な絵がすべて自動的に出てくる。次章の π 共役系とヒュッケル理論は、本章の σ・π の区別が頭の中にあって初めてきれいに読める。

## 本論 1 — LCAOという発想

分子の中で電子の在処を表す関数が **分子軌道(molecular orbital, MO)** $\psi$(プサイ)である。正確な $\psi$ を求めるには多体シュレディンガー方程式を直接扱う必要があるが、直観的な近似が一つある。原子 A 上の原子軌道 $\phi_A$(ファイ)と原子 B 上の $\phi_B$ を持ってきて、その二つの線形結合で書こう、というものだ。最も単純な等核二原子(H₂⁺ または H₂)では二つの原子が化学的に等価なので、対称性から $|c_A| = |c_B|$ が強制される。可能な組合せは次の二つしか残らない:

$$
\psi_\pm = c_A \phi_A \pm c_B \phi_B.
$$

規格化条件 $\int |\psi_\pm|^2\,d\vec r = 1$ を課すと、二つの原子軌道の間の **重なり積分(overlap integral)** $S = \langle\phi_A|\phi_B\rangle$ が自動的に現れて

$$
\psi_\pm = \frac{1}{\sqrt{2(1 \pm S)}}\,(\phi_A \pm \phi_B)
$$

となる。$+$ 符号の方は二原子間の領域で二つの 1s が *建設的*に重なり、電子密度が核の間に積み上がる **結合性(bonding)軌道**。$-$ 符号の方は二核の間にちょうど節(node)が立って電子密度が核間から逃げてしまう **反結合性(antibonding)軌道**である。慣習的にそれぞれ $\sigma$ と $\sigma^*$ で表す。

## 本論 2 — 結合と反結合は対称ではない

LCAO から落ちてくる最も重要な定量的事実は、二つの MO のエネルギーが原子準位に対して **対称ではない** という点である。ハミルトニアン行列要素を次のように書く。同じ原子上で評価した $H_{AA} = H_{BB} = \alpha$(オンサイト、**クーロン積分**)、二原子に跨って評価した $H_{AB} = \beta$(オフサイト、**共鳴積分**またはホッピング)。安定な結合では $\beta$ は負となる。すると二つの MO のエネルギーは

$$
E_\pm = \frac{H_{AA} \pm H_{AB}}{1 \pm S} = \frac{\alpha \pm \beta}{1 \pm S}.
$$

原子準位 $\alpha$ に対して、結合性軌道は $\,|(\beta - \alpha S)/(1+S)|\,$ だけ *下がり*、反結合性軌道は $\,|(\beta - \alpha S)/(1-S)|\,$ だけ *上がる*。分母の $1 \pm S$ の違いから、**反結合の不安定化は結合の安定化より大きい**。この一行があの有名な帰結を生む — 二つの原子が電子を 2 個持ち寄れば(H₂)二つとも結合性軌道に入って分子は安定。4 個持ち寄ると(仮想の He₂)2 個は結合、2 個は反結合に入ることになるが、反結合側の損が結合側の得を上回るので *正味は損*。だから He₂ は分子として存在できない。ヘリウムが希ガスにとどまる量子力学的な理由はここにある。

## 本論 3 — σ と π

LCAO は 1s 同士の足し算で終わるわけではない。足し合わせる原子軌道の形は多様で、それに応じてできあがる MO の **空間対称性** も変わってくる。結合軸(通常 $z$ 軸)の回りに回転させて MO が変わらない — つまり軸まわりに円筒対称な — 場合、その MO を $\sigma$ と呼ぶ。1s + 1s、二つの 2p$_z$ が *end-on* に向かい合う重なりが σ である。一方、結合軸の上で MO の値が 0 となる節面を持つ場合は $\pi$ と呼ぶ。二つの 2p$_x$ または 2p$_y$ が *side-on* に平行に重なってできるのが π である。

この分類は化学結合の階層と過不足なく対応する。単結合 = 1σ。二重結合 = 1σ + 1π。三重結合 = 1σ + 2π。σ 結合は核の間に電子密度が最も積み上がる形なので *短く強い*。π 結合は脇から薄く重なる形なので σ より弱いが、*二重・三重結合の追加エネルギー*と*二重結合まわりの回転剛性*はすべてこの π 結合に由来する。次章のブタジエンやベンゼンといった π 共役系は、この σ 骨格はそのまま凍結し、π 軌道だけを取り出してヒュッケル近似で解いていくことになる。

## Pythonで確かめる

```python
# H2+ の結合/反結合曲線を LCAO + Slater 1s で描く。
# 原子単位: hbar = m_e = e = 4πε₀ = 1. 長さはボーア半径単位。
import numpy as np
import matplotlib.pyplot as plt

R = np.linspace(0.5, 6.0, 200)

# 重なり積分とハミルトニアン行列要素(H2+の1s-1s閉形式)
S   = (1 + R + R**2 / 3) * np.exp(-R)
T_AA = 0.5 * np.ones_like(R)
V_AA = -1.0/R + (1.0 + 1.0/R) * np.exp(-2*R)
T_AB = -0.5 * (S - 2 * (1 + R) * np.exp(-R))
V_AB = -(1 + R) * np.exp(-R) / R

H_AA = T_AA + V_AA
H_AB = T_AB + V_AB

# 電子エネルギー + 核間反発 1/R
E_plus  = (H_AA + H_AB) / (1 + S) + 1.0 / R   # 結合性 σ
E_minus = (H_AA - H_AB) / (1 - S) + 1.0 / R   # 反結合性 σ*

i_min = int(np.argmin(E_plus))
print(f"結合曲線の最小点: R ≈ {R[i_min]:.2f} a0, E ≈ {E_plus[i_min]:.3f} Hartree")

plt.plot(R, E_plus,  label="σ (結合性)")
plt.plot(R, E_minus, label="σ* (反結合性)")
plt.axhline(-0.5, color="0.6", lw=0.8, ls="--", label="H + H⁺ 解離極限")
plt.xlabel("R / a₀"); plt.ylabel("E / Hartree")
plt.title("H₂⁺: LCAO 結合/反結合曲線")
plt.legend(); plt.tight_layout(); plt.show()
```

結合曲線の最小が $R \approx 2$ a$_0$($\approx 1.06$ Å)付近で $E \approx -0.602$ Hartree($\approx -16.4$ eV)に落ちれば、H + H⁺ 解離極限 $-0.5$ Hartree から約 $0.10$ Hartree 下がったことになる。実験的な結合エネルギー $2.79$ eV と同じオーダーであり、LCAO という一行の処方が定性的にも定量的にも働いていることを自分の手で確かめたことになる。
