# 分子と光の相互作用 — 吸収スペクトルと選択則

> 分子がどの光子を受け入れるかは共鳴条件だけでは決まらない — 遷移双極子モーメントがゼロなら、その遷移は禁制になる。

## はじめに

第4章で光子は量子状態をつなぐ粒として登場し、$h\nu = E_f - E_i$ という共鳴条件が吸収・放出の振動数を決めた。しかし共鳴条件を満たすからといって、あらゆる遷移が実際に起こるわけではない。本章を終えると読者は、吸収スペクトルのある一本がなぜそこにあるか(共鳴)、なぜある一本はまったく存在しないか(選択則)、そしてなぜピークが無限に鋭くなく一定の幅をもつか(線形)を、それぞれ一文で言えるようになる。

## 本論 1 — 吸収とフェルミの黄金律

遷移が起こる *確率* を扱うには、振動数 $\nu$ の光を時間とともに振動する電場とみなし、その電場が分子をわずかに揺さぶることを摂動として扱う。角振動数 $\omega$ (オメガ、$\omega = 2\pi\nu$) で振動する電場による、状態 $|i\rangle$ から $|f\rangle$ への遷移率は、最低次の摂動論で

$$
W_{i \to f} = \frac{2\pi}{\hbar} |\langle f | \hat{\mu} \cdot \vec E_0 | i \rangle|^2\, \delta(E_f - E_i - \hbar\omega)
$$

で与えられる。これが **フェルミの黄金律(Fermi's Golden Rule)** の双極子近似形である。ここで $\hat\mu = q \vec r$ は **双極子演算子** で、電荷 $q$ が位置 $\vec r$ にあるときの双極子モーメントを表す。$\vec E_0$ は光の電場振幅、ディラックのデルタ $\delta(E_f - E_i - \hbar\omega)$ はエネルギー保存 — すなわち共鳴条件 — を強制する。

要は行列要素 $\langle f | \hat\mu | i \rangle$ である。この量を **遷移双極子モーメント(transition dipole moment)** と呼ぶ。遷移率はこの量の絶対値の二乗に比例するので、もし対称性によって $\langle f | \hat\mu | i \rangle = 0$ となれば、共鳴条件をどれだけ正確に合わせても遷移は起こらない。その遷移を **禁制(forbidden)** という。選択則はまさにここから生まれる。

## 本論 2 — 選択則

原子の一電子遷移を見よう。$\langle f | \hat\mu | i \rangle$ の空間部分は $\hat r$ を挟んでいるが、$\hat r$ は角運動量で見ると $\ell = 1$ の成分をもつ(方向ベクトルは $p$ 軌道のように変換する)。角運動量の加法則により、$\langle \ell_f | \hat r | \ell_i \rangle$ は $\ell_f = \ell_i \pm 1$ のときだけゼロでない。これが有名な $\Delta\ell = \pm 1$ 則である — $s \to p$、$p \to d$ は許容、$s \to s$、$s \to d$ は禁制。

原子のほかの電気双極子則も同じ出どころから来る。磁気量子数は $\Delta m_\ell = 0, \pm 1$、スピンは $\Delta s = 0$(電気双極子近似では光はスピンを直接ひっくり返せない)。

分子では則が二手に分かれる。振動遷移は遷移の途中で双極子モーメントが *変化* しなければならない — だから等核二原子分子の $N_2$、$O_2$ は赤外線を吸収できない。伸びても双極子モーメントがゼロのままだからだ。電子遷移の場合、中心対称をもつ分子では遷移が起こるためにパリティが $g \to u$ に変わらなければならない(ラポルテ則)。同じパリティどうしでは $\langle f | \hat r | i \rangle$ の積分の被積分関数が奇関数になり、積分がゼロになる。

## 本論 3 — 線形:ローレンツ曲線

エネルギー準位は無限に鋭くはない。励起状態は有限の寿命 $\tau$ (タウ) をもつため — 時間-エネルギーの不確定性から — エネルギーに幅が生じる。この **自然幅(natural linewidth)** は次の **ローレンツ曲線(Lorentzian profile)** を作る:

$$
L(\omega) = \frac{\gamma/\pi}{(\omega - \omega_0)^2 + \gamma^2}
$$

ここで $\omega_0$ は共鳴角振動数、$\gamma$ (ガンマ) は半値半幅である。半値全幅(FWHM)は $2\gamma = 1/\tau$ — 励起状態が速く崩れるほどピークは広がる。

実際の気体ではさらに二つが加わる。分子がそれぞれ異なる速度で動きドップラー偏移を受ける **ドップラー広がり**、そして分子どうしが衝突して位相が乱れる **衝突広がり** である。ドップラー寄与はガウス形なので、観測されるピークはローレンツとガウスの **畳み込み** である **フォークト曲線(Voigt profile)** になる。さらに分光器そのものの分解能がもう一度畳み込みとして働き、スペクトルをいっそう滑らかにならす。

## Pythonで確かめる

```python
# 三つのローレンツピークを作り、分光器の分解能を模した
# ガウスカーネルで畳み込み、ピークがならされる様子を見る。
import numpy as np
import matplotlib.pyplot as plt

w = np.linspace(0, 7, 700)          # 光子エネルギーのグリッド [eV]
dw = w[1] - w[0]

def lorentzian(w, w0, gamma):
    return (gamma / np.pi) / ((w - w0)**2 + gamma**2)

# 三つの遷移: 2.0, 3.5, 5.0 eV、自然幅 gamma = 0.1 eV
gamma = 0.1
spec = sum(lorentzian(w, w0, gamma) for w0 in (2.0, 3.5, 5.0))

# 分光器の分解能: FWHM 0.3 eV のガウスカーネル(同じグリッド間隔)
fwhm = 0.3
sigma = fwhm / (2 * np.sqrt(2 * np.log(2)))
g = np.arange(-3 * sigma, 3 * sigma, dw)
kernel = np.exp(-g**2 / (2 * sigma**2))
kernel /= kernel.sum()              # 正規化
conv = np.convolve(spec, kernel, mode='same')

plt.plot(w, spec, label='ローレンツ3本の和')
plt.plot(w, conv, label='分解能で畳み込み後')
plt.xlabel('光子エネルギー [eV]')
plt.ylabel('吸収(任意単位)')
plt.title('吸収スペクトルと分光器の分解能')
plt.legend(); plt.tight_layout()
plt.show()
```

畳み込んだ曲線は三つのピークの中央のディテールを洗い流し、より低く広くする。もし三つのピークの間隔が分解能 0.3 eV より狭ければ、畳み込みのあとは三つが一つの広いピークに融合して見分けがつかなくなる — 分光器の分解能とは、すなわち「区別できる二つの遷移の最小エネルギー間隔」なのである。
