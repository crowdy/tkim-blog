# 分子の形と電子状態 — VSEPR・混成・項記号

> 価電子の数だけから分子の形を予測し、同じ論理で原子の基底状態に $^{2S+1}L_J$ という名札を貼る。

## はじめに

第7章では多電子分子のスレーター行列式と分子軌道(MO)を扱った。本章はもう少し手で掴める絵 — *分子はなぜその形を取るのか* — まで降りてくる。H$_2$O が曲がり、NH$_3$ が傘形で、CH$_4$ が正四面体である理由は、ほどいてみればすべて「電子対はできるだけ遠ざかろうとする」という一文の帰結である。本章を終えると、読者は中心原子まわりの結合原子数と孤立電子対の数だけから分子の形を即座に予測でき、その予測が混成軌道という *数学的* な絵とどう噛み合うか、さらに原子のレベルでは同じ思考が $^{2S+1}L_J$ という項記号に整理されることまで一行で説明できる。

## 本論 1 — VSEPR:電子対が位置を決める

**VSEPR(valence-shell electron-pair repulsion、原子価殻電子対反発)** モデルの前提はただ一つ。中心原子まわりの電子対 — 結合対であれ孤立電子対(lone pair)であれ — は互いに反発するので、できるだけ遠ざかる配置を取る。この一行から形が決まる。

数える量は **立体数(steric number, SN)** である。

$$
\text{SN} = (\text{結合した原子の数}) + (\text{孤立電子対の数})
$$

立体数ごとの標準配置は次の通り。

- **SN = 2** → 直線形、結合角 180°。例:BeCl$_2$、CO$_2$。
- **SN = 3** → 平面三角形、120°。例:BF$_3$。
- **SN = 4** → 正四面体、109.5°。例:CH$_4$。孤立電子対 1 個で **三角錐(trigonal pyramidal)** に崩れて NH$_3$(約 107°)。孤立電子対 2 個で **折れ線形(bent)** にさらに狭まって H$_2$O(約 104.5°)。
- **SN = 5** → 三方両錐(trigonal bipyramidal)、軸 90°・赤道 120°。例:PCl$_5$。
- **SN = 6** → 正八面体、90°。例:SF$_6$。

H$_2$O の結合角が正四面体の理想値 109.5° よりも *さらに狭い* 104.5° である理由は一つ。孤立電子対は陽子に縛られておらず空間的に広がっていて、結合対より多くの場所を占める。だから孤立電子対が結合対を *外側から内側へ* 押して角度を縮める。NH$_3$ の 107° も同じ効果の弱い版である。VSEPR は量子力学を持ち出さずにここまで定量的に当てる。

## 本論 2 — 混成:原子軌道を作り直す方法

VSEPR が *どんな形になるか* を語るなら、**混成(hybridization)** は *その形に合わせて中心原子の原子軌道(AO)をどう組み直すか* を語る。

炭素の基底状態の電子配置は $1s^2 2s^2 2p^2$ だが、CH$_4$ のように等価な四本の結合を作るとき、私たちは $2s$ 1 個と $2p$ 3 個を混ぜて四つの等価な混成軌道 $sp^3$ を作る。この四軌道は正四面体の四頂点を向く。BF$_3$ やエチレンの炭素のように平面三角形が必要なら $2s$ + $2p_x$ + $2p_y$ を混ぜて三つの $sp^2$ と一つの余った $2p_z$ になり、アセチレンの炭素のように直線が必要なら $2s$ + $2p_x$ だけを混ぜて二つの $sp$ と二つの余った $2p$ になる。規則は一行だ。

$$
\text{立体数} = \text{混成軌道の数}
$$

残った非混成 $p$ 軌道は隣の原子の同じ $p$ と出会って $\pi$ 結合を作る(第6章)。二重結合は $sp^2$ + $\pi$、三重結合は $sp$ + $\pi \times 2$ である。

一つ注意。混成は *測定された事実* ではなく *事後的な記述* である。分子が正四面体の形を取るという実験結果を受け取って、それに合う軌道基底を *私たちが選んだ* のだ。それでもこの記述のおかげで、結合角・$\pi$ の存在・平面性といった性質を一度に整理できる。

## 本論 3 — 原子の項記号 $^{2S+1}L_J$

同じ思考を *原子* のレベルで整理すると **項記号(term symbol)** $^{2S+1}L_J$ になる。一つの原子の全軌道角運動量を $L$、全スピンを $S$(大文字、全電子の和)、全角運動量を $J = L + S$ と呼ぼう。表記法は次の通り。

- 上付き $2S+1$ — **多重度(multiplicity)**。
- 中央の文字 — $L$ 値。$L = 0, 1, 2, 3 \to$ S, P, D, F。
- 下付き — $J$。

この名札は、同じ電子配置の中で微妙に異なる状態どうしを区別するのに使う。どれが *基底状態* になるかは **フントの規則(Hund's rules)** が決める。

1. $S$ をできるだけ大きく。
2. 同じ $S$ の中では $L$ をできるだけ大きく。
3. 半分より満たされていない殻では $J$ をできるだけ小さく(半分以上なら逆)。

窒素($1s^2 2s^2 2p^3$)で直接やってみよう。$2p$ の三席 $m_\ell = -1, 0, +1$ に電子三つが入るが、フント 1 がその三つをすべて同じスピンに揃えて $S = 3/2$。磁気量子数の和は $-1 + 0 + 1 = 0$、すなわち $L = 0$ → 文字は S。$J$ は $|L - S|$ から $|L + S|$ までのうち、半分より満たされていない場合は最小値を取る:$J = 3/2$。結果は

$$
^4 S_{3/2}
$$

これが窒素の基底状態の名札だ。多重度 4 は「同じエネルギーのミクロ状態が $2S+1 = 4$ 通り」という意味である。

分子にも同種の記号がある。H$_2$ の基底状態は $^1\Sigma_g^+$、O$_2$ の基底状態は $^3\Sigma_g^-$(だから酸素分子は常磁性だ)。$\Sigma, \Pi, \Delta$ は分子軸方向の角運動量の $L$ 対応で、$g/u$ は反転対称、$\pm$ は鏡映対称のラベルである。より深い分類は第9章の分光学で再び出会う。

## Pythonで確かめる

```python
# VSEPR 分類器:結合数と孤立電子対数だけから立体数と形を返す。
# 実験的な結合角も併せて出力してみる。

SHAPES = {
    (2, 0): ("linear",               180.0),
    (3, 0): ("trigonal planar",      120.0),
    (4, 0): ("tetrahedral",          109.5),
    (3, 1): ("trigonal pyramidal",   107.0),
    (2, 2): ("bent",                 104.5),
    (5, 0): ("trigonal bipyramidal",  90.0),
    (6, 0): ("octahedral",            90.0),
}

def vsepr(bonding, lone):
    sn = bonding + lone
    shape, angle = SHAPES[(bonding, lone)]
    return sn, shape, angle

cases = [
    ("H2O",   2, 2),
    ("NH3",   3, 1),
    ("CH4",   4, 0),
    ("BeCl2", 2, 0),
    ("BF3",   3, 0),
    ("PCl5",  5, 0),
    ("SF6",   6, 0),
]

print(f"{'formula':<6}  {'SN':>2}  {'shape':<22}  angle")
print("-" * 46)
for formula, b, l in cases:
    sn, shape, angle = vsepr(b, l)
    print(f"{formula:<6}  {sn:>2}  {shape:<22}  {angle:5.1f}°")
```

出力の各行が本文で予測した形・角度と一致すれば、「電子対は遠ざかろうとする」という一行の規則で七つの分子の形状を手に掴んだことになる。
