# 多電子原子 — スピン・パウリ・周期表

> 電子は上下二つの顔を持つ小さな磁石だ — スピンとパウリの排他律がスレイター行列式と周期表をどう丸ごと決めてしまうのか。

## はじめに

第2章で私たちは、水素原子の1電子が $(n, \ell, m_\ell)$ という三つの量子数でラベル付けされる軌道 (orbital) に住むことを見た。本章はその絵に決定的な一枚を重ねる — **スピン (spin)** である。スピンが入った瞬間、一つの軌道には電子が二つまで入れるようになり、その「二つまで」という上限を **パウリの排他律 (Pauli exclusion principle)** が *因数分解できない行列式* の形で強制する。本章を終えると、ヘリウムからウランまでの電子配置を丸暗記ではなく *再構成* できるようになり、周期表の縦・横がどの量子数の可視化なのかを一行で答えられるようになる。

## 本論 1 — スピン: 電子が持ち歩くもう一つの顔

電子は空間位置のほかに **内在角運動量 (intrinsic angular momentum)** を一単位だけ持ち歩く。これを $\vec S$ と書く。量子力学のきまりで、その大きさは

$$
|\vec S| = \hbar \sqrt{s(s+1)}, \qquad s = \tfrac{1}{2}
$$

に固定されている。$\hbar$ (エイチバー、換算プランク定数) は量子力学であらゆる角運動量の単位を決める定数。重要なのは、電子では $s = 1/2$ が *くぎ付け* になっている点だ — 電子は「半整数スピン (half-integer spin)」の粒子、すなわち **フェルミ粒子 (fermion)** である。

スピンのもう一つの自由度は $z$ 軸への *射影* である:

$$
S_z = m_s \hbar, \qquad m_s = \pm \tfrac{1}{2}.
$$

つまり電子のスピンは「上」 ($m_s = +1/2$、$\uparrow$ と書く) と「下」 ($m_s = -1/2$、$\downarrow$) の二値しか取らない。結果として、一つの空間軌道があれば、それにスピン上・下を掛け合わせた **スピン軌道 (spin-orbital)** が自動的に二つ付いてくる。

これで一電子の正体を完全に指定する量子数は四つになる — $(n, \ell, m_\ell, m_s)$。許される値は $n = 1, 2, 3, \dots$、$\ell = 0, 1, \dots, n-1$、$m_\ell = -\ell, \dots, +\ell$、そして $m_s = \pm 1/2$。化学者の慣習で $\ell = 0, 1, 2, 3$ をそれぞれ $s, p, d, f$ 軌道と呼ぶ。(ちなみにこの "$s$" はスピンの $s$ ではなく、19世紀の分光学の *sharp* に由来する偶然の衝突なので混同しないこと。)

## 本論 2 — パウリの排他律とスレイター行列式

電子はフェルミ粒子なので、二電子のラベルを入れ替えると全体の波動関数の符号が反転しなければならない — これを **反対称 (antisymmetric)** という。式で書けば

$$
\Psi(1, 2) = - \Psi(2, 1).
$$

ここで「1, 2」は二電子の座標とスピンをまとめて指すラベルである。これは単なる約束事ではなく、実験で検証された自然の基本則であり、電子に限らずすべての半整数スピン粒子が従う。

二電子がそれぞれ別のスピン軌道 $\phi_a, \phi_b$ に入っているとしよう。上の反対称性を満たす最も簡単な形は

$$
\Psi(1, 2) = \frac{1}{\sqrt{2}}\left[\phi_a(1)\phi_b(2) - \phi_a(2)\phi_b(1)\right] = \frac{1}{\sqrt{2}}\det\!\begin{pmatrix}\phi_a(1) & \phi_b(1) \\ \phi_a(2) & \phi_b(2)\end{pmatrix}
$$

である。右辺は 2×2 行列の **行列式 (determinant)** であり、この形で書いた多電子波動関数を **スレイター行列式 (Slater determinant)** と呼ぶ。行列式は二つの行を入れ替えると符号が反転し、二つの列が一致すると 0 になる量だが、この二つの性質がそのまま次の結論を与える:

- 電子 1, 2 のラベル (=行ラベル) を入れ替えれば $\Psi$ の符号が反転する — *反対称性が自動* に組み込まれる。
- 二つのスピン軌道が同じなら、つまり $\phi_a = \phi_b$ なら行列式の二つの列が一致して $\Psi \equiv 0$ になる — *同じスピン軌道に二電子は入れない*。これが最強の形の **パウリの排他律** である。

スレイター行列式は $N$ 電子にも一般化される: $N \times N$ 行列の行列式を $\sqrt{N!}$ で正規化したものがそれだ。第12章で分子軌道法 (MO) を扱うときにこの形式が本格的に再登場する。

## 本論 3 — 周期表を読む: 構成原理とフントの規則

これで二つの道具を揃えた。あとはこれで周期表全体を *組み立てる*。**構成原理 (Aufbau principle)** はいたって素直で、「エネルギーの低いスピン軌道から順に詰めろ」である。一つの軌道にスピン上・下の二席があるから二電子が入り、満席になれば次へ。多電子原子で観測される平均的な充填順は

$$
1s \to 2s \to 2p \to 3s \to 3p \to 4s \to 3d \to 4p \to 5s \to 4d \to 5p \to \cdots
$$

であり、各 $s, p, d, f$ の収容人数は $2, 6, 10, 14$ である ($2(2\ell+1)$ から直に出る)。注目すべき二点:

1. $s, p, d, f$ の **ブロック (block)** は周期表の縦の塊にそのまま対応する — $s$ ブロック 2 列、$p$ ブロック 6 列、$d$ ブロック 10 列、$f$ ブロック 14 列。
2. $4s$ が $3d$ より *先に* 埋まるという妙な順序 — これが第4周期最初の遷移金属 (transition metal) を面白くする。遷移金属化学の機微はこの一行の順番ひねりから始まる。

そしてもう一つ、**フントの規則 (Hund's rule)**: エネルギーが等しい軌道が複数あるとき (たとえば $2p$ の三つの軌道 $p_x, p_y, p_z$)、電子はまず *同じスピン向きでひとつずつ別の軌道に* 入る。だから炭素 (C、電子 6 個) の基底状態は $1s^2 2s^2 2p^2$ のうち、二つの $2p$ 電子が一つの軌道に対を組まずに、異なる二つの軌道に平行スピンで一個ずつ入っている。この一事が炭素化学 — つまりほぼすべての有機化学 — の出発点を決めてしまう。

## Pythonで確かめる

```python
# ヘリウム基底状態の二電子スレイター行列式を組み立て、反対称性を確認する。
# 空間 1s 軌道 phi(r) = (1/sqrt(pi)) exp(-r)、単位は a_0 = 1。
import numpy as np

def phi_1s(r):
    return np.exp(-r) / np.sqrt(np.pi)

def alpha(spin):           # スピン上のみ 1
    return 1.0 if spin == "up" else 0.0

def beta(spin):            # スピン下のみ 1
    return 1.0 if spin == "down" else 0.0

def chi_up(r, spin):       # 1s、スピン上のスピン軌道
    return phi_1s(r) * alpha(spin)

def chi_dn(r, spin):       # 1s、スピン下
    return phi_1s(r) * beta(spin)

def slater(e1, e2):
    r1, s1 = e1
    r2, s2 = e2
    M = np.array([[chi_up(r1, s1), chi_dn(r1, s1)],
                  [chi_up(r2, s2), chi_dn(r2, s2)]])
    return np.linalg.det(M) / np.sqrt(2)

e1 = (0.5, "up")
e2 = (1.2, "down")
psi_12 = slater(e1, e2)
psi_21 = slater(e2, e1)   # 電子ラベルを入れ替え
print(f"Psi(1, 2) = {psi_12: .6f}")
print(f"Psi(2, 1) = {psi_21: .6f}   (符号が反対であるべき)")
print(f"合計       = {psi_12 + psi_21: .2e}  (≈ 0)")
```

$\Psi(1,2)$ と $\Psi(2,1)$ が符号反転した同じ値で、両者の和が機械精度でゼロに落ちれば、スレイター行列式がフェルミ粒子の反対称性を *自動的に* 保証していることを手で触ったことになる。両電子に同じスピン軌道 (たとえば両方 $\chi_\uparrow$) しか割り当てないように式を書き換えると行列式は 0 になり — パウリの排他律が式一行に落ちる。
