# ポアソン括弧と可積分性

> 位相空間上の関数たちの間のリー括弧 — ポアソン括弧でハミルトン力学を一行に書き直し、その視点から可積分系と作用–角変数がどう立ち上がるかを見る。

## はじめに

本書の最終章である。これまで積み上げてきた道具 — 多様体、微分形式、ラグランジアン、変分、対称性、ハミルトニアン、正準変換 — が一点で交わる。その点が **ポアソン括弧** である。本章を読み終えた読者は、ハミルトン方程式を座標を介さずに $\dot f = \{f, H\}$ という一行で書けるようになり、「可積分系」という言葉が漠然とした形容ではなく、正確な定義をもつ幾何学的事実であることを理解する。さらにその定義の上で、調和振動子があらゆる力学書の最初の例題に登場する理由が — 作用–角変数の視点から — 一枚の絵で見えるようになる。

## 本論 1 — ポアソン括弧、位相空間上のリー括弧

自由度 1 の位相空間で、二つの滑らかな関数 $f(q, p), g(q, p)$ の **ポアソン括弧(Poisson bracket)** を次のように定める:

$$
\{f, g\} = \frac{\partial f}{\partial q}\frac{\partial g}{\partial p} - \frac{\partial f}{\partial p}\frac{\partial g}{\partial q}
$$

自由度 $n$ の場合は同じ項をすべての $i = 1, \ldots, n$ について和をとる ($\sum_i (\partial_{q^i} f \, \partial_{p_i} g - \partial_{p_i} f \, \partial_{q^i} g)$)。掛け算のように見えるが、実は 5 章のベクトル場上の **リー括弧(Lie bracket)** と同じ役割を果たす演算である — 二つの対象から新しい対象を作るが、その結果が二つの対象の「交換不能性」を測る。

ポアソン括弧の四つの性質がすべてを支える:

1. **双線形性**: 両変数について線形。
2. **反対称性**: $\{f, g\} = -\{g, f\}$。特に $\{f, f\} = 0$。
3. **ライプニッツ則**: $\{f, gh\} = \{f, g\}h + g\{f, h\}$ — 積に対する微分のように振る舞う。
4. **ヤコビ恒等式**: $\{f, \{g, h\}\} + \{g, \{h, f\}\} + \{h, \{f, g\}\} = 0$。

この四つの性質によって、位相空間上の滑らかな関数の空間 $C^\infty(T^*M)$ は無限次元の **リー代数(Lie algebra)** をなす。位置と運動量の間で一度計算しておくと便利だ: $\{q^i, q^j\} = 0, \{p_i, p_j\} = 0, \{q^i, p_j\} = \delta^i_{\ j}$ ($\delta^i_{\ j}$ はクロネッカーのデルタ)。この三行が量子力学の正準交換関係 $[\hat q^i, \hat p_j] = i\hbar \delta^i_{\ j}$ の古典版である。

ポアソン括弧でハミルトン方程式を書き直すと、11 章で見た二行が一行に統合される。任意の位相空間関数 $f(q, p, t)$ の時間微分は

$$
\dot f = \{f, H\} + \frac{\partial f}{\partial t}
$$

$f = q^i$ を代入すると $\dot q^i = \partial H / \partial p_i$、$f = p_i$ を代入すると $\dot p_i = -\partial H / \partial q^i$ — ハミルトン方程式がそのまま落ちる。この表現の真価は別のところにある: **$\{f, H\} = 0$ ならば $f$ は運動の積分(保存量)** である。9 章で見たネーターの定理は、ポアソン括弧の言葉では一行の命題になる。二つの関数がポアソン可換($\{f, g\} = 0$)とは、各々が生成する流れが互いに可換であることと同値である — 5 章で見たベクトル場のリー括弧との橋がここに架かる。

## 本論 2 — リウヴィル可積分性

自由度 $n$ のハミルトン系が **リウヴィルの意味で可積分(Liouville integrable)** であるとは、位相空間上に $n$ 個の滑らかな関数 $F_1, \ldots, F_n$ が存在して次の三条件を満たすことをいう:

1. そのうちの一つは $H$ 自身である — 通常 $F_1 = H$ とする。
2. $n$ 個の関数は **関数的に独立** である — 微分 $dF_1, \ldots, dF_n$ がほぼ至るところで一次独立。
3. 二つずつすべて **ポアソン可換** である — 任意の $i, j$ について $\{F_i, F_j\} = 0$。この条件を「**対合的(in involution)**」と呼ぶ。

条件 3 が要である。単に保存量が $n$ 個あるというだけでなく、その保存量たちが **互いの流れとも両立する** という強い条件である。すなわち $F_i$ が生成する正準変換の流れと $F_j$ が生成する流れが可換で、位相空間に格子のような座標を引けるという意味だ。

リウヴィル–アーノルドの定理(Arnold)はこの条件のもとで全体像を一文で捉える: **共通等値面 $\{F_i = c_i\}$ がコンパクトかつ連結ならば、それは $n$ 次元トーラス $T^n$ であり、運動はそのトーラス上の等速な平行移動である**。このときトーラス上の座標として **作用–角変数(action–angle variables)** $(J_i, \theta_i)$ が自然に定まる — 作用 $J_i$ はトーラスにラベルを付け、角度 $\theta_i \in [0, 2\pi)$ はトーラス上の位置を指定する。この座標系ではハミルトニアンが作用だけの関数 $H(J)$ になり、ハミルトン方程式が

$$
\dot J_i = 0, \qquad \dot\theta_i = \omega_i(J) := \frac{\partial H}{\partial J_i}
$$

として解ける。すべての運動が **一定の振動数を持つトーラス上の直線運動** だということだ。可積分系の力学が本質的に終わる場所がここである。

実際に可積分な系は非常に稀である — ケプラー問題、調和振動子、剛体の自由回転、コワレフスカヤの独楽あたりが伝統的なリストだ。一般の系は可積分ではなく、わずかな摂動でトーラス構造が部分的に壊れる(KAM 定理)。それでも限られた可積分例が学部の力学教材の 90 % を占める理由は、この絵が綺麗で手で最後まで解けるからである。

## 本論 3 — 調和振動子の作用–角変数

自由度 1 の 1 次元調和振動子で全てを手に取ろう。ハミルトニアンは

$$
H(q, p) = \frac{1}{2}p^2 + \frac{1}{2}\omega^2 q^2
$$

(単位質量 $m = 1$、振動数 $\omega$、オメガ)。位相空間の等値面 $H = E$ は半軸 $\sqrt{2E}$ と $\sqrt{2E}/\omega$ の楕円である。自由度が一つなので可積分性の条件は $F_1 = H$ 自身ひとつで満たされる。

作用–角変数を手で取ってみよう。次の変換を導入する:

$$
q = \sqrt{\frac{2J}{\omega}}\, \sin\theta, \qquad p = \sqrt{2J\omega}\, \cos\theta
$$

この変換のヤコビアンを直接計算すると $\partial(q, p) / \partial(\theta, J) = 1$ — すなわち体積要素 $dq \wedge dp = d\theta \wedge dJ$ を保つ。これは 11 章で定義した **正準変換** の条件である。両式をハミルトニアンに代入すると

$$
H = \tfrac{1}{2} \cdot 2J\omega \cos^2\theta + \tfrac{1}{2}\omega^2 \cdot \tfrac{2J}{\omega}\sin^2\theta = J\omega (\cos^2\theta + \sin^2\theta) = \omega J
$$

ハミルトニアンが **角度に依存しなくなる** — 作用 $J$ だけの関数になった。ハミルトン方程式はそのまま落ちる:

$$
\dot J = -\frac{\partial H}{\partial \theta} = 0, \qquad \dot\theta = \frac{\partial H}{\partial J} = \omega
$$

$J$ は定数、$\theta$ は一定の角速度 $\omega$ で増加する。$(\theta, J)$ 平面では軌道が **水平な直線** — 最も単純な運動である。もとの位相空間 $(q, p)$ では楕円に沿って回る間の時刻が非等速だったものが、作用–角座標では等速になる。これが作用–角変数の与える報酬である。

$J$ の物理的意味も添えておく価値がある。一周期にわたる位相空間面積を $2\pi$ で割った量 — $J = (1/2\pi)\oint p \, dq$ — がちょうど上で導入した $J$ と一致する。ボーア–ゾンマーフェルトの量子化条件 $J = n\hbar$ が落ちる場所もここだ。作用は、量子力学と古典力学を結ぶ橋で最も自然に持ち上げられる量である。

## Pythonで確かめる

```python
# 調和振動子 (m=1, omega=1.5) を RK4 で積分しながら
# 作用 J = H/omega と位相 theta = arctan2(p, omega*q) を毎ステップ記録する。
# (q, p) は楕円、(theta, J) は水平な直線になるはず。
import numpy as np
import matplotlib.pyplot as plt

omega = 1.5
def rhs(q, p):
    return p, -omega**2 * q

def rk4_step(q, p, dt):
    k1q, k1p = rhs(q, p)
    k2q, k2p = rhs(q + 0.5*dt*k1q, p + 0.5*dt*k1p)
    k3q, k3p = rhs(q + 0.5*dt*k2q, p + 0.5*dt*k2p)
    k4q, k4p = rhs(q + dt*k3q,     p + dt*k3p)
    return (q + dt*(k1q + 2*k2q + 2*k3q + k4q)/6,
            p + dt*(k1p + 2*k2p + 2*k3p + k4p)/6)

dt, T_end = 0.01, 12.0
N = int(T_end / dt)
q = np.empty(N+1); p = np.empty(N+1)
q[0], p[0] = 1.2, 0.0
for k in range(N):
    q[k+1], p[k+1] = rk4_step(q[k], p[k], dt)

H = 0.5*p**2 + 0.5*omega**2*q**2
J = H / omega
theta = np.arctan2(p, omega*q)
print(f"max relative drift of J = {(J.max() - J.min())/J[0]:.2e}")

fig, ax = plt.subplots(1, 2, figsize=(9, 4))
ax[0].plot(q, p); ax[0].set_xlabel("q"); ax[0].set_ylabel("p"); ax[0].set_title("(q, p) 楕円")
ax[1].plot(theta, J, '.', ms=2); ax[1].set_xlabel(r"$\theta$"); ax[1].set_ylabel("J")
ax[1].set_title(r"$(\theta, J)$ 水平線"); ax[1].set_ylim(J[0]*0.9, J[0]*1.1)
plt.tight_layout(); plt.show()
```

$J$ の相対ドリフトが $10^{-6}$ 未満に落ちれば、RK4 が作用を十分よく保存している証拠である。左の図はもとの位相空間の楕円、右の図は作用–角座標での水平線 — 同じ運動を二つの座標系で見た二つの顔である。
