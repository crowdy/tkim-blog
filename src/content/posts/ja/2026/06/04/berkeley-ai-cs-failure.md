# UC Berkeley CS 10 の 35.3 % 不合格率 — 'AI 依存' と '先行数学の崩壊' という二つの原因の切り分け

> 2026 年 6 月 4 日、The Daily Californian の報道が HN に上がり 765 点と 737 コメントを集めた。UC Berkeley の入門 CS 講座 CS 10 ('The Beauty and Joy of Computing') の春学期不合格率が 35.3 % に跳ね上がった。直前の二学期 (Spring 2024, 2025) の 10 % 未満から一学期で三倍以上の飛躍だ。同じ学期 CS 61A の平均成績は C+ (2.3 GPA)、学科推奨ガイドライン (2.8 ~ 3.3) の遥か下に落ちた。EECS 127 の D / F 合計は 16.8 % — 平時の 5 % の三倍以上だ。報道が指摘した二つの原因は「LLM に頼りすぎた課題遂行」と「先行の線形代数・ベクトル微積分の欠如」だ。二つの原因は同じものなのか、別物なのか。

## 導入 — '35.3 % 不合格率' という数字の重み

まず数字の輪郭を整理する。CS 10 は Berkeley の「CS 非専攻者でも受講可能な入門講座」という自己描写を持つ。Snap! / Python で基礎アルゴリズムと抽象化を教える一学期の講座で、受講者層は多様だ — 専攻決定前の新入生、人文・社会科学の学生、CS 専攻へ移ろうとする編入生。その講座の春学期不合格率 35.3 % が意味するのは、同じ講座の直前学期不合格率 10 % 未満との比較で最も明確になる。受講者層の社会構成、講義資料、教員はほぼ同じだ。ただ一つ変わったものがある — LLM の利用可能性だ。

同じパターンが他の講座でも見られる。CS 61A は Berkeley CS 専攻の最も標準的な初回講座だ。その講座の平均成績が C+ まで落ちたことは学科の自己標準 (2.8 ~ 3.3) の明確な違反であり、学科のガイドラインが平均を引き上げるように設計されていることを踏まえれば、より大きなシグナルだ。EECS 127 の 16.8 % D / F 合計は別のパターンを見せる — この講座は最適化モデルを扱う応用数学講座で、線形代数 / ベクトル微積分の十分な先行が前提だ。その先行の崩壊がこの講座の不合格率で直接測定される。

報道が引用した二人の教員の診断が、事件の二つの筋を分けて指摘する。第一に、Dan Garcia の陳述 — CS 10 の春学期不合格率の一部は「捕まって処分された」不正行為の結果だ。30 人近い学生が take-home 試験で LLM 使用を発見された。つまり不合格率の一部は「学生ができなかった結果」ではなく「できなかったが LLM で隠した結果」だ。第二に、Gireeja Ranade の陳述 — 学生たちが線形代数の先行で詰まった。そして一人の学生の先行講座に「open-internet, open-AI 政策」があった事実を彼女自身が発見した。つまり不合格率のもう一つの一部は「先行講座が測れなかった欠如」が次の講座で露呈した結果だ。

本稿はこの二つの原因を切り分けて分析する。二つの原因は同じ「AI 依存」の二つの表現に見えるが、実は政策的処方の方向が正反対だ。その切り分けを明確にしなければ、処方が誤った方向に向かう。

## 本文 1 — 'AI 依存' の表層: 不正行為摘発とその限界

まず第一の原因 — 「学生が試験で LLM を使った」 — の作動様式を解いてみる。この原因は最も明確で、処方が最もシンプルに見える。take-home 試験を in-person 試験に変え、コード作成課題をライブコーディング面接に変え、不正行為摘発システムを強化する。Garcia の「no curve, transparent letter-grade threshold」政策はこの処方の一形態だ — 学生が他の学生との比較ではなく絶対基準で評価されるようにすれば、「他人が LLM を使うから自分も使わねば」という競争圧力の一部が消える。

この処方の限界は即座に見える。HN で最も共感を集めた一つのコメントが正確にこの限界を指摘する — 情緒をそのまま訳せば — 「課題は完全に無採点 (ungraded) にしなければならない ... それが不正行為をしたくない人が不正行為をしなくてもよくなる唯一の方法だ (Homework needs to be completely ungraded ... that's the only way to make sure that people who don't want to cheat have to cheat anyway)」。この一行が指すのは、競争圧力の非対称だ。90 % の学生が LLM で課題を素早く終わらせる中、10 % だけが自力でやれば、その自力でやる 10 % は時間不足で他科目で損をする。その損を避けるためにその 10 % も LLM を使うことになる。「LLM を使うことが正直な学生にも強制的に使わせる」構造が核心問題だ。

この非対称は単純な不正行為摘発では解けない。摘発システムが完璧でない事実 — LLM 出力の統計的指標は急速に消えつつある — もあるが、より深い問題は「課題の評価上の意味そのものが崩れた」という点だ。課題単位で学生の理解を測る従来の評価方式は、学生が同じ作業を自分の頭でする前提に立っていた。その前提が LLM で崩れたとき、同じ評価が測っているのは「学生の理解」ではなく「学生の LLM 利用効率」だ。二つは別の能力だ。

Garcia の政策変更 — 「no curve」 — は一筋の答えだが、それは不正行為のインセンティブを下げるだけで、評価の意味を回復しない。評価の意味の回復はより難しい作業だ — 「LLM を使うユーザー」が何をできるべきかの基準を再定義し、その基準に合う新しい評価ツール (ライブコーディング, ホワイトボード説明, コードレビュー実演) を作らねばならない。これは一人の教員の個別決定では終わらない。講座設計、学科政策、大学レベルの一貫した標準が必要だ。

もう一つの非対称がある。Ranade が発見した「先行講座の open-AI 政策」だ。一つの講座の教員が不正行為を厳格に防いでも、その学生が受講した先行講座が LLM を自由に許していたなら、その学生の頭にあるべき線形代数の知識はすでに欠落している。これは一つの講座の評価が単一講座の責任ではなく講座チェーン全体の責任だ、ということを意味する。Berkeley のような大規模大学で講座間の政策一貫性を作ることは、ほぼ行政の時間単位 (数学期) を要する。その時間が流れる間に、より多くの学生が空の先行を持ったまま次の講座へ進学する。

## 本文 2 — '先行数学の崩壊' のより深い層

第二の原因 — 線形代数 / ベクトル微積分の欠如 — を解くと、より深い診断が見える。この原因は第一の原因 (LLM 依存) の結果に見え得るが、実はそれよりも大きな構造 — 「抽象化の梯子」の段階的崩壊 — の一部だ。

伝統的に大学 CS の学習梯子はこう構成されてきた。高校の代数 / 幾何 → 大学 1 年の微積分 / 線形代数 → CS 1 年のアルゴリズム入門 → CS 2 年のデータ構造 / 離散数学 → CS 3 年のアルゴリズム / OS / コンピュータアーキテクチャ → CS 4 年の応用 (ML, コンパイラなど)。各段階が次の段階の抽象化を可能にしてきた。線形代数なしに機械学習を理解できず、離散数学なしにアルゴリズムの正当性証明を追えない。

この梯子の中間段階 — 大学 1 年の微積分 / 線形代数 — が崩れれば、その上のあらゆる段階が揺らぐ。EECS 127 の不合格率はこの揺らぎの直接的な測定だ。学生は講座の資料 (ラグランジュ乗数法、凸最適化、KKT 条件) を覚えられるが、その資料の意味を自分の頭で再構成できない。試験で少しでも変形された問題が出れば解けない。LLM を使えば解けるかもしれないが、試験は LLM なしで受ける。

この診断が 5/31 の本ブログ分析 (Brethorst の「ドメイン専門性が本当の堀だった」) と出会う地点がある。Brethorst の診断は AI がコード作成とドメイン専門性を切り分け、後者だけが価値あるものとした、というものだった。Berkeley の事件はその切り分けのもう一つの側面を見せる — **AI が学生の表層的能力 (課題完遂) と深い能力 (数学的抽象化の理解) を切り分け、後者が測れなくなる状況を生んだ**。両方とも同じ構造 — 「AI が媒介能力の単価を下げ、本当に核心となる能力だけを残す」 — の二つの表現だ。

ここで最も重要な切り分けが現れる。Brethorst の診断で「本当の堀」がドメイン専門性なら、Berkeley の事件で「本当の堀」は何か。単に「AI なしでコードを書ける能力」ではなく、**数学的抽象化を自分の頭で構成し検証する能力** だ。この能力は LLM が補助できるが置き換えられない — 少なくとも現在の LLM の限界の中では。新しいアルゴリズム設計、整合性証明、性能最適化の限界分析のような作業はすべてこの能力に縛られている。

HN のもう一つのコメントがこの診断の時間次元を指摘する — 情緒の要約 — 「博士レベルの専門家ですら LLM なしでブレインストーミングし、コードを書き、深く考え、文章を書く能力を失いつつある (Many of them can no longer brainstorm, code, think deeply, or write without an LLM present doing 90% of the work)」。学生だけの問題ではない。同じ萎縮がシニアエンジニア、博士、教員にも起きる。Berkeley の学部講座は最も速く最も鮮明な測定値であるに過ぎず、同じ萎縮が産業全般で進行中だ。

この診断の最も暗い部分は、その萎縮が自己強化ループだという点だ。学生が LLM で課題を終え、その学生が卒業して職場で LLM で働き、その職場で作られたコード / 分析 / 文章が次の LLM 学習データの一部となる。そのデータの上で学習された次の LLM が再びより多くの学生の課題を終える。このループの中で「自分の頭で数学的抽象化を構成する能力」の単価がどこで再び上がるか、という問いが次の世代の教育の最大の単一の問いだ。

## 本文 3 — 学校の時間定数と道具の時間定数

この事件が単一の大学の単一の学期の事件ではなく時代の診断であるという点は、HN のもう一つのコメントが正確に指す — 情緒の要約 — 「学校は年単位で動いているのに、AI は週 / 月単位で進歩する (Schools work on timescales of years, AI is advancing on the timescale of weeks and months)」。この時間定数の非対称が事件の構造的原因だ。

大学の行政の時間定数を解くと — 新規講座の導入は通常 2 学期の検討 → 1 学期の試行 → 次の学期の正規化で、約 2 年かかる。講座評価政策の変更は 1 年単位だ。学科レベルの一貫した標準 (例えば「LLM 使用政策の標準化」) の導入は 2 ~ 3 年かかる。入学政策の変更 (例えば ACT / SAT の再導入、1,300 名以上の UC 教員が請願した事案) は 5 ~ 10 年単位だ。

LLM の時間定数は正反対だ。GPT-3 のリリースは 2020 年 6 月。ChatGPT が 2022 年 11 月。GPT-4 が 2023 年 3 月。Claude 3.5 Sonnet が 2024 年 6 月。Claude 4 が 2025 年 5 月。Claude 4.8 が 2026 年 5 月。約 6 ~ 12 ヶ月単位の大きな跳躍があり、その間に毎月の小さな跳躍 (Cursor, Aider, Claude Code のような道具の登場と進化) が挟まる。学生が学期開始時に対面した LLM の能力と学期終了時に対面した LLM の能力が違う。一つの講座の設計がその差に追いつけない。

この時間定数の非対称が生む結果は二つに分かれる。第一に、講座設計が毎回一歩遅れる。一学期の LLM 依存パターンを見て次学期の政策を作れば、その政策が施行される時には LLM の能力がまた一段階跳躍している。Berkeley の春学期 35.3 % が秋学期に 20 % に下がっても、それは診断の解決ではなく一学期遅れた適応に過ぎない。第二に、学生の学部 4 年間に LLM の能力が少なくとも二 ~ 三度の大きな跳躍をする。その跳躍ごとに「同じ講座の測定値」の意味が違う。4 年前の入学生が対面した CS 10 と 4 年後の入学生が対面する CS 10 は同じ名前の講座だが別物だ。

この二つの結果が合わさると、**「学校が道具に追いつく」モデル自体の限界が露呈する**。学校が追いつけない速度なら、学校の役割そのものを再定義しなければならない。「課題を採点する場」から「道具なしでも可能な深い抽象化を保証する場」への再定義が一筋だ。「4 年学位」から「6 ヶ月単位のモジュラー資格証」への再定義がもう一筋だ。二つとも行政的に非常に難しいが、行政の難しさが時間定数の非対称の解決を生むわけではない。

Berkeley の 35.3 % が指すのは単純な一学期の事故ではなく、大学システムの時間定数が道具の時間定数に追いつけないという事実の最初の大きな可視化だ。次の 5 年以内に同じパターンがアメリカ / 韓国 / 日本のすべての大規模大学で測定されるだろう。

## 結論 — '二つの原因の切り分け' が生む二つの処方

Berkeley の事件が HN の 765 点を集めた本当の理由は、それが「AI 依存」という一語で束ねられる二つの別の原因 — 直接的な不正行為と先行能力の崩壊 — を切り分けて示したことだ。二つの原因は処方が異なる。

第一の原因 (不正行為) の処方は評価形式の変化だ。take-home を in-person に、自由応答をライブ説明に、no-curve 政策で競争圧力を下げる方向だ。この処方は一講座 / 一学期単位で実行可能だ。Berkeley の Garcia が始めた「no curve」がその例だ。この処方の限界は評価の意味そのものは回復しない、という点だ。

第二の原因 (先行崩壊) の処方は講座チェーン全体の一貫した政策だ。一講座の教員が自分の講座だけ厳格にすれば、次の講座の学生は空の先行を持って到着する。学科レベル、さらには大学レベルの一貫した「LLM 使用の段階的政策」が必要だ。入門講座では LLM 使用禁止、中級講座では LLM 使用可能だが評価では禁止、上級講座では LLM 活用を明示的評価項目に — そのような段階的政策が一仮説だ。この処方は行政の時間定数 (2 ~ 3 年) を要し、道具の時間定数 (6 ~ 12 ヶ月) とぶつかる。

最後に一つの問いを投げかけて閉じる。我々が卒業した (または卒業する) 大学の講座が教えた能力のうち、「道具なしでも可能な深い抽象化能力」の割合はどれくらいだったか。その割合が我々の想像より低いなら、我々は学位が指す能力と実際の能力の差を自分で埋めなければならない。Berkeley の 35.3 % はその差を可視化した最初の大きな測定で、同じ測定がやがて我々のところにも到着する。
