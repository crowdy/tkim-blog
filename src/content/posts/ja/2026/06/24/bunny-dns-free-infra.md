# Bunny が DNS を無料にする：インフラ無料化戦略の解剖

> DNS クエリに課金しないという一企業の宣言が、Hacker News のトップで 907 点を集めた。インフラが一つずつ無料になっていく流れの上で、無料化は何を代償に要求するのか。

## 導入 — もう一つのインフラが無料になる日

2026 年 6 月 24 日 (KST)、Bunny.net のブログに 「We're making Bunny DNS free」 という短いタイトルの記事が掲載された。Hacker News のトップで 907 点を集め、コメント 267 件が付いた。内容は一行で要約できる。DNS クエリにもう課金しない。アカウントあたり 500 ドメインまで無料、クエリ無制限、リクエスト単位の課金なし、そして 「中核機能を enterprise プランの裏に隠さない」 。

この発表が大きな反応を得た理由は、単なる値下げの知らせだからではない。インフラの一つの層がまた無料になっていく流れの一場面だからである。TLS 証明書が Let's Encrypt で無料になり、CDN の無料ティアが Cloudflare で標準になった。今度は DNS クエリ課金が崩れる。だが無料化は慈善ではない。無料で解放されたすべてのインフラの背後には、その無料化で何を得ようとするのかという計算がある。本稿は Bunny DNS 無料化を三つの層位で解剖する。技術的に何か、経済的にどんな計算か、そして産業全体のどんな流れの一場面か。

## Bunny DNS の技術解剖 — 「基本ルックアップ」 ではないルーティングエンジン

まず押さえるべきは、Bunny DNS が単純な名前ルックアップサービスではないという点である。無料化発表の重みは 「無料」 という言葉より 「何を無料で解放するのか」 にある。Bunny が無料で開放したのは、月およそ 2000 億件のクエリを 30 万ドメインにわたって処理する全地球的分散ルーティングエンジンそのものだ。

**インテリジェントルーティングエンジン。** 伝統的な権威 DNS は、ドメイン名を受け取り、あらかじめ登録されたレコードを返す静的なルックアップ機である。Bunny のエンジンはその上にルーティング判断を載せる。smart records と呼ぶこの層は、クエリが届いた位置、各エンドポイントの状態、レイテンシを総合して応答を動的に決める。health monitoring が組み込まれており、死んだエンドポイントは自動で応答から外れる。これが無料ティアに含まれる点が発表の核心だ。通常この種の機能は traffic steering や geo-routing という名で enterprise プランに縛られる項目だった。

**IPv6 デュアルスタックの自動化。** Bunny DNS は IPv4 と IPv6 を自動で同時提供する。運用者が AAAA レコードを別途管理しなくてもデュアルスタック応答が構成される。些細に見えるが、IPv6 採用が運用負担ゆえに遅れる現実において、自動化には実質的な価値がある。

**DNSSEC と NSEC Black Lies。** セキュリティ面で最も精緻なのが DNSSEC の実装だ。DNSSEC は DNS 応答に署名を付けて改竄を防ぐ標準だが、古典的な実装には zone enumeration という副作用がある。存在しない名前をクエリすると 「この名前とあの名前の間には何もない」 という NSEC レコードが署名されて返るが、これを繰り返すと攻撃者はゾーン全体のレコード一覧を引き出せてしまう。NSEC Black Lies 技法はこの問題を回避する。クエリされたその名前のすぐ次の名前までを 「ない」 と署名して返すことで、改竄防御は維持しつつゾーン構造は露出しない。無料 DNS でこの水準の実装を標準提供する点は、技術的な本気度のシグナルだ。

**現代的なレコードタイプ。** HTTPS、SVCB、TLSA、CDS、CDNSKEY といった新型レコードをサポートする。HTTPS と SVCB レコードは、クライアントが最初の接続前に ALPN、ポート、ECH といった接続パラメータを先取りして往復を減らせるようにする。TLSA は DANE ベースの証明書ピン留め、CDS と CDNSKEY は DNSSEC の鍵ロールオーバー自動化に使われる。これらは DNS が単なるアドレス帳を超えて接続交渉の制御平面へと進化していることを示すレコード群であり、Bunny がこの流れの最新を追っていることを意味する。

**プラットフォーム統合 — ここが真の設計意図だ。** Bunny は DNS レコード画面からそのまま 「1-Click Acceleration」 で当該レコードに CDN を付け、「1-Click Security」 で Bunny Shield を有効化できるようにした。他の DNS から移行する際は、既存ゾーンを自動スキャンしてレコードをそのまま複製する。つまり DNS は入口であり、その入口でワンクリックして CDN、セキュリティ、アクセラレーションが付随する構造だ。技術解剖の結論は明確である。無料化されたのは DNS という独立した製品ではなく、より大きなプラットフォームへ入っていくよく設計された玄関である。

## 無料化の経済学 — $1/月の最低課金が真のフックだ

ではなぜ企業はこの玄関を無料で開けるのか。無料 DNS の経済学を理解するには loss-leader の論理を見る必要がある。loss-leader はそれ自体では損をしても客を引き寄せ、別の場所で回収する撒き餌商品だ。スーパーが牛乳を原価以下で売って客を入れ、買い物かご全体で利益を出すのと同じである。Bunny の DNS 無料化は教科書的な loss-leader だ。

**DNS の限界費用はもともと低い。** 核心は DNS クエリ一件を処理する限界費用がそもそも非常に小さいという事実だ。応答は数百バイトで、大半はキャッシュされ、再クエリは権威サーバまで届きもしない。anycast ネットワークがすでに敷かれていれば、クエリ一件の増分費用はほぼ 0 に収束する。つまり Bunny が 「放棄」 するクエリ課金売上は、会社がすでに CDN のために運用する全地球的エッジ網の上では、実は大きな費用ではない。無料化の損失は帳簿上の売上機会の放棄であって、実際の現金流出ではない。これが無料化を負担可能にする第一の構造だ。

**$1/月の最低課金 — 無料の底に敷かれた真のフック。** 発表で最も注目すべき一行は 「無料」 ではなく、アカウントあたり月最低 1 ドルの支出下限である。DNS 自体は無料だが、アカウントを維持するにはプラットフォーム全体で月 1 ドル以上を使う関係が前提となる。この 1 ドルは金額が重要なのではない。無料ユーザーを決済関係のある顧客へ変える点が重要だ。決済手段が登録され、請求書が発生し、会社との関係が無料から有料へ越える臨界線 — その線を越えさせる装置が 1 ドルの下限だ。いったんカードが登録され毎月の請求が回る顧客は、その後 CDN トラフィックやストレージやビデオストリーミングへ支出を増やす摩擦が著しく低い。無料 DNS はこの臨界線まで連れてくる道具である。

**顧客獲得ファネルとしての DNS。** 一般的な SaaS の顧客獲得費用 (CAC) は広告と営業で支出される。インフラ企業が無料製品を撒き餌に使うと、その無料製品の限界費用がそのまま変形された CAC になる。DNS の限界費用がほぼ 0 であるため、Bunny の実質 CAC は競合の広告ベース CAC より構造的に低くなりうる。DNS を移す行為そのものが、すでに高い購入意向を持つユーザーを選別してくれるからだ。ドメインの DNS を一社に委ねるとは、その会社を信頼インフラとして受け入れたというシグナルであり、そのシグナルを送ったユーザーは同じ会社の CDN とストレージを追加で使う可能性が高い。

**競争構図 — Cloudflare と Route53 の間。** この戦略は新しくない。先例を作ったのは Cloudflare だ。Cloudflare は無料 DNS と無料 CDN ティアで膨大なユーザー基盤を集めたのち、enterprise とセキュリティ製品で回収してきた。Bunny の無料化はそのプレイブックを追いつつ、Cloudflare が受ける批判 — 巨大な規模、不透明な enterprise 営業、トラフィックが一社へ集中することで生じるプライバシー懸念 — の反対側に自分を置こうとするポジショニングだ。反対の端には AWS Route53 がある。Route53 はホスティングゾーンとクエリに正直に課金する pay-per-query モデルであり、ゆえに無料ではない。代わりに AWS エコシステムの中に深く結びつき、他の AWS サービスとの統合を売る。NS1 のような専門 DNS 事業者は精緻な traffic management を有料で売る。Bunny の位置はこの三者の間だ。Route53 ほどロックインされず、NS1 の高度な機能を無料で解放し、Cloudflare より小さく透明だと主張する位置。無料化はその位置を占めるための手段である。

**日本市場の文脈。** この構図を日本の企業の選択に重ねると、力学はさらに鮮明になる。日本企業の DNS / CDN 選定は長らく AWS Route53 の優位の下にあった。基幹システムが AWS に乗っている以上、DNS も Route53 で揃えるのが摩擦の少ない既定値であり、pay-per-query の課金は問題視されにくい。そこへ Cloudflare が無料ティアと WAF を武器に Web 系・スタートアップを中心に採用を伸ばしてきた。だが日本の大企業には別の変数がある。個人情報保護法の下でのデータレジデンシーの懸念だ。DNS / CDN がトラフィックをどこで処理し、ログをどの法域に保存するのかは、エンタープライズの調達で繰り返し問われる論点である。Bunny がスロベニア拠点の EU 企業であることは、この点で両義的に働く。GDPR 圏の事業者という安心感と、日本のデータを EU 系事業者に委ねることへの慎重さが同居する。無料という入口の魅力と、データ主権という出口の警戒 — 日本企業の選定はこの二つの間で揺れる。

## インフラのコモディティ化の大局 — control plane を誰が握るか

一歩引いて見ると、Bunny DNS 無料化はインフラのコモディティ化というより大きな流れの一場面である。かつて金を取っていたインフラ層が一つずつ無料の既定値になっていく。最も鮮明な先例が Let's Encrypt だ。TLS 証明書は一枚あたり数十から数百ドルを取る商品だった。Let's Encrypt が無料の自動発行を標準にしたのち、証明書で稼ぐ事業は事実上消滅した。価値は証明書そのものから、証明書を自動で管理してくれるプラットフォームへ移った。DNS クエリ課金の崩壊は同じ物語の次の章である。

**なぜ DNS が戦略的な位置か。** 証明書と DNS が無料になることには共通点がある。どちらも限界費用が低く、どちらも control plane だ。control plane であるという点が決定的である。DNS を握る会社はトラフィックがどこへ向かうかを決める。同じドメインのクエリを自社 CDN へ送るか、どのエッジへルーティングするか、どのセキュリティ層を通すかを DNS 応答一行で定める。誰かの DNS をホスティングするとは、その人のトラフィックをルーティングし、加速し、保護する位置を占めるという意味だ。だから DNS は無料で解放しても惜しくない。無料で解放する代わりに control plane を手に入れるからだ。data plane — 実際のトラフィック、ストレージ、コンピュート — で回収すればよい。

**ベンダーロックインと開放性の緊張。** ここで無料の代償が現れる。無料 DNS はユーザーを一つのエコシステムへ引き込む入口だ。1-Click で CDN とセキュリティが付く滑らかな統合は利便であると同時にロックインである。一社の DNS、CDN、ストレージ、ビデオ、画像最適化を一画面で使ううちに、別の場所へ移す費用は毎月静かに上がっていく。DNS 自体は標準プロトコルなので移行が技術的に難しくないが、その上に積まれた smart records の設定とプラットフォーム統合は移行されない。無料化は開放性のジェスチャーに見えるが、統合の滑らかさが深いほど実質的な移動費用は大きくなる。これが無料インフラが要求する静かな代償だ。

**展望。** 流れの方向は明らかだ。インフラ各層のマージンは圧縮され、価値は統合プラットフォームとプレミアムサービスへ移動する。DNS の次に無料化圧力を受ける層 — 基本 CDN 帯域、小規模オブジェクトストレージ、エッジ関数の無料枠 — はすでに競合間の出血競争の対象だ。生き残る事業者は単一層でマージンを守る会社ではなく、複数の無料層を撒き餌に敷き、統合された上位サービスで回収する会社だろう。Bunny の多角化したポートフォリオ — CDN、ビデオストリーミング、ストレージ、画像最適化、コンテナ、データベース、エッジスクリプティング — は、まさにそのモデルへの賭けである。

## 結論 — 無料の裏面を読む方法

「我々は Bunny DNS を無料にする」 という発表を読む方法は二つある。一つは額面どおりだ。一つのインフラ企業が小さな費用のサービスをユーザーに返した好意。もう一つは戦略の解剖だ。限界費用がほぼ 0 の control plane を撒き餌に敷き、$1/月の最低課金で決済関係を作り、1-Click 統合で上位サービスに縛るよく設計された顧客獲得ファネル。

二つの読みは矛盾しない。ユーザーにとって無料 DNS は実際に得である — 高品質な anycast ルーティング、精緻な DNSSEC、現代的なレコードを無料で得る。同時に会社にとっても得だ — control plane を握りエコシステムの入口を広げる。無料化の真の含意は、二つのうちどちらが勝つかではなく、インフラの価値がどこへ移動しつつあるかだ。個別の層は無料になり、価値は統合と信頼へ移っていく。だから無料 DNS を評価する正しい問いは 「本当に無料か」 ではなく 「この入口から入ると、どのエコシステムのどの位置に立つことになるか」 だ。Bunny の発表が指すのは一社の価格政策ではなく、インフラを選ぶすべての決定が、ますます層ではなくエコシステムを選ぶ決定になっていくという事実である。
